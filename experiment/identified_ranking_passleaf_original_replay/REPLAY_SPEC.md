# PASSLEAF original-code 3x3 replay

Frozen before the replay result is observed.

## Question

Does uncertainty about which admissible NL27K graph completion is used change PASSLEAF-DistMult top-1 predictions more than ordinary training-seed variation, when PASSLEAF is trained with the original unKR implementation and checkpoint-selection rule?

## Fixed design

- Dataset: NL27K only.
- Worlds: LOWER, NOMINAL, UPPER, generated by the same PR13 world constructor used in the previous 3x3 diagnostic.
- Seeds: 11, 23, 37 crossed with all three worlds.
- Queries: the same first 500 strong Q queries (`confidence > 0.85`) from the deterministic PR13 test split.
- Downstream model: unKR PASSLEAF with DistMult using `config/nl27k/PASSLEAF_nl27k.yaml`.
- PASSLEAF settings inherited from that config: 512 dimensions, 10 negatives, 40 max epochs, `T_new_semi=20`, `T_semi_train=30`, learning rate 1e-3, weight decay 0.01.
- Checkpoint selection and early stopping: `Eval_MAE`, minimized, matching the original `PASSLEAFdemo.py` behavior.
- Included world facts have confidence 1.0. Mapping-only sentinel rows have confidence 0 and are removed before optimization.
- Primary prediction identity: raw top-1 tail entity. Filtering is used only for nominal MRR/Hits@10 competence diagnostics.

## Primary comparison

For each fixed seed, compare raw top-1 winners across the three worlds. For each fixed world, compare raw top-1 winners across the three seeds.

`DeltaDisagree = WorldPairDisagree_matched - SeedPairDisagree_matched`.

## Decision rule

Continue this identified-ranking direction only if both conditions hold:

1. NOMINAL seed-11 filtered Hits@10 on the frozen 500-query set is at least 0.20; and
2. `DeltaDisagree >= 0.10`.

Otherwise the diagnostic result is `KILL` for this direction. The previously computed world-variance share and 2-of-3 reproducibility quantities remain descriptive diagnostics and cannot rescue a failed excess-disagreement gate.

No threshold, dataset, query set, model, world construction, or seed set may be changed after seeing the replay result.
